Heart Disease MLOps Project

Prerequisites

- Docker Desktop installed
- Kubernetes enabled in Docker Desktop
- kubectl available on the system

Local Testing Instructions:

1. Ensure Docker Desktop Kubernetes is running.

2. Deploy the application

	kubectl apply -f deployment/deployment.yaml
	kubectl apply -f deployment/service.yaml

3. Verify deployment

	kubectl get pods
	kubectl get deployments
	kubectl get services

4. Forward the Kubernetes service port

	kubectl port-forward service/heart-api-service 8080:80

5. Open Swagger UI

	http://localhost:8080/docs

6. Test the prediction endpoint

Use POST /predict with patient data in JSON format.

Example:

{
  "age": 63,
  "sex": 1,
  "cp": 3,
  "trestbps": 145,
  "chol": 233,
  "fbs": 1,
  "restecg": 0,
  "thalach": 150,
  "exang": 0,
  "oldpeak": 2.3,
  "slope": 0,
  "ca": 0,
  "thal": 1
}

7. View logs

	kubectl logs <pod-name>

8. View application status

	kubectl get pods
	kubectl get deployments
	kubectl get services
